# Rashindi — Portfolio

Personal portfolio site built with React, Vite and Tailwind CSS v4.

## Run it

```bash
npm install
npm run dev      # local dev server
npm run build    # production build in dist/
npm run preview  # serve the production build
```

## Editing content

- Text, links, services, tech list and projects: `src/content.js`
- Colours, fonts and animations: the `@theme` block in `src/index.css`
- Images go in `public/images/` (a placeholder shows until each file exists):
  `workspace.jpg`, `candid.jpg`, `apartner.jpg`, `livin.jpg`, `aurelle.jpg`
- CV: `public/Rashindi-CV.pdf`
