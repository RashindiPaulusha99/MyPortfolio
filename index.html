The story so far

Let's start with the good bits…

I'm a full-stack software engineer based in Sri Lanka. My heart lives in Java and Spring Boot — designing clean APIs, sensible data models and services that keep running quietly in the background. On the surface, I build with React, caring about the small details that make an interface feel calm and easy to use.

I graduated with a First Class BSc in Computer Science & Software Engineering from the University of Bedfordshire, UK, and I've been turning ideas into working products ever since — from property management platforms to a matchmaking app of my own.

I like software that gets out of the way. If the people using it never have to think about it, I've done my job.
